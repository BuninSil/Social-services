# NEONHUB · MLBB

Соцсеть сообщества Mobile Legends: Bang Bang — форум, личные сообщения, профили
игроков с рангом и мейн-героем, модерация. На голом Node: ни одной внешней
зависимости, ни сборки, ни внешней СУБД.

```bash
npm start              # → http://localhost:3000
PORT=8080 npm start    # на другом порту
```

Нужен **Node 22.5 или новее** — проект использует встроенный модуль `node:sqlite`.
На Node 22–23 он требует флага, который уже прописан в `npm start`. Если ваша версия
Node ругается на `--experimental-sqlite` (в Node 24+ SQLite стабилен и флаг не нужен),
запускайте `npm run start:stable`.

При первом запуске база создаётся и наполняется демо-контентом: 5 игроков,
19 постов и 14 комментариев по всем разделам.

## Аккаунты

Демо-аккаунты, пароль у всех `demo1234`:

| Ник | Роль | Что можно посмотреть |
|---|---|---|
| `Savage` | админ | панель модерации целиком, выдача ролей, баны |
| `Turtle` | модератор | панель без выдачи ролей |
| `Retrib`, `MidDiff`, `GoldLane` | игроки | обычный вид |

Регистрация открыта. **Первый зарегистрировавшийся в пустой базе получает права
админа** — иначе панель будет некому открыть. Если поднимаете с нуля для себя,
удалите `data/` и зарегистрируйтесь первым.

## Что умеет

**Аккаунты и права**
- регистрация и вход, пароли через `scrypt` с солью, сессии в HttpOnly-куке
- три роли: игрок → модератор → админ; роли раздаёт только админ
- админ не может менять роль другого админа
- бан рвёт все сессии игрока и закрывает вход; админа забанить нельзя
- выход с текущего устройства и выход отовсюду; смена пароля тоже сбрасывает все сессии
- удаление своего аккаунта под пароль, вместе со всем содержимым

**Соцсеть**
- личные сообщения с непрочитанными; чужую переписку не отдаёт даже модератору
- подписки и лента только по ним
- уведомления о лайках, ответах и подписках
- блокировка игрока: рвёт подписки, закрывает ЛС и убирает его из ленты
- правка своих постов и ответов с пометкой «изменено»
- жалобы на посты и игроков с проверкой объекта и защитой от дублей
- закрепление постов модератором
- поиск по игрокам, лента страницами по 30

**Профиль игрока**
- мейн-герой (42 героя), основная линия, ранг, ID в игре, винрейт
- статус-подпись под ником, описание, неоновый акцент профиля

**Тематика игры**
- 5 линий, 10 рангов от Воина до Бессмертного, 42 героя
- 8 разделов: мета и патчи, герои, гайды, драфт, хайлайты, поиск тиммейтов, скины, флудилка
- отметки Savage / Maniac / Legendary / MVP на постах
- посты поиска тиммейтов: кого ищешь и от какого ранга

**Защита**
- ограничение частоты: вход, регистрация, посты, ответы, ЛС и жалобы
- вход отвечает за одинаковое время независимо от того, занят ник или нет
- ники сравниваются с учётом регистра кириллицы, «Мифик» и «МИФИК» — один и тот же ник
- заголовки CSP, `X-Frame-Options`, `Referrer-Policy`, `Permissions-Policy`
- кука `Secure` при `NEONHUB_SECURE=1` (за HTTPS-прокси)

**Интерфейс**
- адаптив от 390px, `prefers-reduced-motion`, горячие клавиши (`/`, `Esc`, `Ctrl+Enter`)

## Как устроено

```
server.js       HTTP-сервер: роутинг /api/*, статика с SPA-фолбэком
lib/db.js       SQLite: схема, индексы, WAL, обёртки над запросами
lib/auth.js     пароли (scrypt), сессии, роли, баны
lib/api.js      домен: посты, ЛС, подписки, жалобы, модерация, витрина
lib/mlbb.js     словарь игры: герои, линии, ранги, разделы, отметки
seed.js         демо-наполнение при первом старте
public/         index.html + styles.css + app.js (SPA на ванильном JS)
data/           база; создаётся сама, в git не попадает
```

Состояние целиком в SQLite с включёнными внешними ключами и WAL. Сессии тоже
в базе, поэтому перезапуск сервера никого не разлогинивает.

## API

| Метод | Путь | Что делает |
|---|---|---|
| `GET` | `/api/meta` | справочник игры: герои, линии, ранги, разделы |
| `POST` | `/api/auth/register` · `/login` · `/logout` · `/logout-all` | аутентификация |
| `GET` `PATCH` `DELETE` | `/api/me` | текущий игрок, правка профиля, удаление аккаунта |
| `POST` | `/api/me/password` | смена пароля |
| `GET` `POST` | `/api/posts` | лента (`channel`, `sort`, `q`, `author`, `hero`, `feed=following`, `limit`, `offset`), создание |
| `GET` `PATCH` `DELETE` | `/api/posts/:id` | пост с ответами, правка, удаление |
| `POST` | `/api/posts/:id/like` · `/pin` · `/comments` | лайк, закрепление, ответ |
| `PATCH` `DELETE` | `/api/comments/:id` | править и удалить свой ответ |
| `GET` | `/api/users?q=` | поиск по игрокам |
| `GET` | `/api/users/:name` · `/followers` · `/following` | профиль и подписки |
| `POST` | `/api/users/:name/follow` · `/block` | подписка и блокировка |
| `GET` `POST` | `/api/notifications` · `/read` | уведомления |
| `GET` | `/api/blocks` | кого я заблокировал |
| `GET` `POST` | `/api/messages` · `/api/messages/:name` | диалоги и переписка |
| `POST` | `/api/reports` | пожаловаться |
| `GET` `POST` | `/api/admin` · `/role` · `/ban` · `/resolve` | панель модерации |
| `GET` | `/api/stats` | витрина сообщества |

## Чего здесь нет

Осознанные пробелы, чтобы не было сюрпризов:

- **восстановления пароля нет** — почту никто не собирает, восстанавливать не через что.
  Забыл пароль — только новый аккаунт или сброс через админа в базе;
- **загрузки картинок нет** — аватар собирается из первой буквы ника и цвета;
- **веток в комментариях нет** — обсуждение плоское;
- **двухфакторной аутентификации и входа через соцсети нет**;
- ограничение частоты живёт в памяти процесса: за несколькими инстансами нужен общий счётчик.

## Демо-версия в браузере

Есть вариант той же соцсети, работающий без сервера — он опубликован отдельной
страницей и открывается с телефона. Там нет настоящей авторизации: профиль лежит
в браузере, переписка хранится в общей базе страницы и не приватна, прав у
модерации нет. Пароли, роли, баны и закрытые личные сообщения работают
только здесь, на сервере.

## Дизайн

Тёмно-синяя ночь и золото интерфейса — палитра самой игры; цвета рангов работают
как акцент и приходят из данных. Глубина строится свечением и волосяными
границами, а не тенями. Акцент профиля задаётся одной CSS-переменной и
наследуется вниз, поэтому шесть палитр не требуют дублирующих стилей.
