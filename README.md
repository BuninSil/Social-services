# NEONHUB

Форум-соцсеть в неоновом минимализме: почти чёрный фон, глубина из света, цвет только в акцентах.
Работает на голом Node — ни одной внешней зависимости, ни сборки, ни базы данных.

```bash
npm start          # → http://localhost:3000
PORT=8080 npm start
```

Демо-контент заливается автоматически при первом запуске.
Аккаунты: `neon`, `kernel`, `glitch`, `vaporwave`, `astra` — пароль у всех `demo1234`.

## Что умеет

- регистрация и вход, сессии в HttpOnly-куке, пароли через `scrypt` с солью
- посты: заголовок, текст, раздел, до 5 тегов; удаление своих
- лайки и комментарии в реальном времени, без перезагрузки страницы
- 6 разделов, три сортировки (горячее / свежее / топ), поиск по тексту и тегам
- профили с кармой, био и выбором неонового акцента (6 палитр)
- правая колонка: пульс сообщества, тренд-теги, топ авторов
- адаптив до 390px, `prefers-reduced-motion`, навигация с клавиатуры (`/` — поиск, `Esc` — закрыть, `Ctrl+Enter` — отправить)

## Как устроено

```
server.js        HTTP-сервер: роутинг /api/*, статика с SPA-фолбэком
lib/api.js       доменная логика: посты, комментарии, лайки, витрина
lib/store.js     JSON-хранилище, scrypt-пароли, сессии
seed.js          демо-контент при первом старте
public/          index.html + styles.css + app.js (SPA на ванильном JS)
data/db.json     состояние; создаётся сам, в git не попадает
```

Состояние лежит в одном JSON-файле: правки копятся и сбрасываются на диск пачкой
через 50 мс, запись атомарная (temp + rename), на `SIGINT`/`SIGTERM` — принудительный flush.
Для демо и небольшого сообщества этого хватает; под реальную нагрузку `lib/store.js`
меняется на SQLite без изменений в остальном коде.

## API

| Метод | Путь | Что делает |
|---|---|---|
| `POST` | `/api/auth/register` · `/login` · `/logout` | аутентификация |
| `GET` `PATCH` | `/api/me` | текущий юзер, правка профиля |
| `GET` `POST` | `/api/posts` | лента (`channel`, `sort`, `q`, `author`), создание |
| `GET` `DELETE` | `/api/posts/:id` | пост с комментариями, удаление |
| `POST` | `/api/posts/:id/like` · `/comments` | лайк-тоггл, ответ |
| `DELETE` | `/api/comments/:id` | удалить свой комментарий |
| `GET` | `/api/users/:username` · `/api/stats` | профиль, витрина |

## Дизайн-решения

Тёмная тема — не инверсия светлой. Насыщенность акцентов поднята, фон уведён почти в чёрный,
глубина строится свечением и тонкими границами (`rgba(255,255,255,.075)`), а не тенями.
Текст — `#e9e9f2` вместо чистого белого: не жжёт глаза на длинном чтении.
Акцент задаётся одной переменной `--accent` и наследуется вниз по дереву, поэтому
шесть пользовательских палитр не требуют ни строчки дублирующего CSS.
